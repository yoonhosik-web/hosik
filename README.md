# 漢検 3級 공부

일본 한자능력검정(漢字検定) 3급 대비용 웹 학습 프로그램입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다(오프라인 동작).

## 기능

- **한자 카드**: 3급 배당한자 284자 + 4급 복습 311자. 음독·훈독·부수·예시어 확인, 검색·섞기, 키보드(Space 뒤집기, ←/→ 이동)
- **퀴즈** (범위·문제 수 선택)
  - 읽기: 단어의 읽기 고르기
  - 쓰기: □에 들어갈 한자 고르기 (같은 음독 한자가 오답으로 나와 동음이자 연습 가능)
  - 부수 / 음독 / 훈독·오쿠리가나
  - 사자성어 빈칸, 대의어·유의어
- **오답 노트**: 틀린 한자를 모아 다시 퀴즈. 모드별 정답률 기록 (브라우저 localStorage에만 저장, 외부 전송 없음)

## 구조

```
index.html        화면
css/style.css     스타일 (다크 모드 지원)
js/data.js        한자·사자성어·대의어/유의어 데이터
js/app.js         카드·퀴즈 로직
tests/            데이터 무결성·문제 생성기 테스트
```

테스트 실행: `node --test tests/*.test.js` (영상 편집기·가계부 테스트 포함)

## 데이터에 대한 주의

- 3급 배당한자는 2020년도 개정 기준 284자(누계 1,623자)로 작성했습니다.
- 읽기는 상용한자표(2010년 고시), 부수는 漢検의 부수 분류를 기준으로 했습니다.
- 작성 환경의 네트워크 제한으로 공식 자료와 한 글자씩 대조하지는 못했습니다. 응시 전 공식 자료로 확인하세요.
  - 日本漢字能力検定協会「級別漢字表」: https://www.kanken.or.jp/kanken/outline/data/outline_degree_national_list20200217.pdf
  - 審査基準: https://www.kanken.or.jp/kanken/outline/degree/standard.html
- 4급 데이터는 313자 중 311자만 들어 있습니다.
- 오류는 `js/data.js`에서 한 줄씩 고치면 됩니다 (형식: `漢字|音|訓|部首|例語:よみ;例語:よみ`).

# 유튜브 영상 만들기 (`video-maker/`)

내 사진·동영상으로 유튜브용 영상, 썸네일, 제목·설명을 만드는 웹 프로그램입니다. 설치 없이 `video-maker/index.html`을 크롬·엣지 등 최신 브라우저로 열면 됩니다.
(파일로 열 때 문제가 있으면 `cd video-maker && python3 -m http.server` 후 http://localhost:8000 으로 여세요.)

**개인정보**: 사진·영상은 서버로 업로드되지 않고 브라우저 안에서만 처리됩니다. 결과 영상·썸네일은 화면을 다시 그린 것이라 원본의 EXIF(촬영 위치 GPS 등)가 들어가지 않습니다. 브라우저에 저장되는 것은 설정값(localStorage)뿐입니다.

## 기능

1. **편집**: 사진·동영상 끌어다 놓기, 순서 바꾸기(끌기/↑↓), 촬영 날짜순 정렬(JPEG EXIF 촬영 시각 사용), 사진별 길이, 동영상 앞뒤 자르기·소리 끄기, 자막, 인트로·아웃트로 문구, 전환 효과(겹치기·검은 화면·밀어내기), 켄 번즈 효과, 흐린 배경 맞춤, 배경 음악(볼륨·동영상 재생 중 자동으로 줄이기·끝부분 페이드아웃)
2. **영상 내보내기**: 16:9 1080p/720p 또는 쇼츠 9:16(1080×1920). 브라우저가 지원하면 MP4, 아니면 WebM (둘 다 유튜브 업로드 가능). 실제 재생 속도로 녹화하므로 영상 길이만큼 걸리며, 그동안 탭을 화면에 띄워 두어야 합니다.
3. **썸네일**: 원하는 장면(자막 제외)을 가져와 큰 글자·강조 문구를 얹어 1280×720 PNG로 저장 (2MB 초과 시 JPG로 자동 압축)
4. **제목·설명**: 자막에서 챕터(타임스탬프) 자동 생성, 해시태그·태그 정리, 글자 수 제한 검사, 복사·텍스트 파일 저장

## 구조

```
video-maker/index.html        화면
video-maker/css/style.css     스타일 (다크 모드 지원)
video-maker/js/timeline.js    타임라인·챕터·메타데이터·EXIF 등 순수 로직 (Node 테스트 대상)
video-maker/js/app.js         캔버스 그리기, 오디오 믹싱, 녹화, UI
tests/video-maker.test.js     로직 테스트
```

## 기준으로 삼은 유튜브 규정 (출처: YouTube 고객센터)

| 항목 | 값 | 출처 |
|---|---|---|
| 권장 비트레이트 (SDR, 24~30fps) | 1080p 8Mbps, 720p 5Mbps | [업로드 권장 인코딩 설정](https://support.google.com/youtube/answer/1722171) |
| 썸네일 | 1280×720, 2MB 이하, JPG·GIF·PNG | [동영상 썸네일 추가](https://support.google.com/youtube/answer/72431) |
| 챕터 | 첫 타임스탬프 0:00, 3개 이상, 각 10초 이상 | [동영상 챕터](https://support.google.com/youtube/answer/9884579) |
| 해시태그 | 60개 초과 시 모두 무시 | [해시태그 정책](https://support.google.com/youtube/answer/6390658) |
| 쇼츠 길이 | 최대 3분 (2024년 10월 15일부터) | [쇼츠 업로드](https://support.google.com/youtube/answer/10059070) |
| 제목 / 설명 / 태그 | 100자 / 5,000자 / 합계 500자 | YouTube 스튜디오 입력 제한 |

- 태그 글자 수는 공백이 있는 태그에 따옴표 2자를 더해 세는 방식으로 계산했는데, 이는 공식 문서가 아닌 스튜디오 동작 기준의 추정치입니다.
- 작성 환경의 네트워크 제한으로 위 링크를 이 시점에 다시 열어 대조하지는 못했습니다. 규정은 바뀔 수 있으니 링크에서 최신 내용을 확인하세요.
- 배경 음악은 저작권 문제가 없는 음원을 쓰세요 ([YouTube 오디오 보관함](https://support.google.com/youtube/answer/3376882)).

## 알려진 제한

- 아이폰 HEIC 사진은 크롬 등에서 열리지 않을 수 있습니다 (JPG로 변환하거나 사파리 사용).
- 녹화 중 다른 탭으로 전환하면 브라우저가 화면 갱신을 멈춰 영상이 끊길 수 있습니다.
- 브라우저를 닫으면 편집 중인 목록은 사라집니다 (원본 파일은 그대로).

# 가계부 (`budget/`)

수입·지출을 기록하고 월별로 정리하는 웹 가계부입니다. 설치 없이 `budget/index.html`을 브라우저로 열면 바로 쓸 수 있습니다(오프라인 동작).

**개인정보**: 모든 기록은 이 브라우저의 localStorage에만 저장되며 외부로 전송되지 않습니다. 브라우저 데이터를 지우거나 다른 기기·브라우저를 쓰면 기록이 보이지 않으니 **설정·백업 → 전체 백업(JSON)** 으로 가끔 백업하세요.

## 기능

- **내역**: 수입/지출, 날짜, 금액(`12,000`, `1.5만`, `3천` 입력 가능), 분류, 결제수단, 메모. 날짜별 묶음 보기, 수정·삭제, 구분·분류·메모 검색 필터
- **월 이동**: ◀/▶, 월 선택. 상단에 그 달 수입·지출·잔액
- **통계**: 분류별 지출·수입 비율, 일별 지출 그래프와 하루 평균, 최근 6개월 수입·지출
- **예산**: 전체·분류별 월 예산과 사용률 (80% 이상 주황, 100% 이상 빨강)
- **고정 수입·지출**: 월세·통신비·급여 등을 "매월 n일"로 등록하면 해당 달을 열 때 자동 추가 (31일로 정하면 짧은 달은 말일). 자동 추가된 항목을 지우면 그 달에는 다시 만들지 않음
- **분류 관리**: 지출·수입 분류 추가·삭제
- **백업·내보내기**: 전체 JSON 백업/복원, 월별·전체 CSV 내보내기(엑셀에서 바로 열리도록 UTF-8 BOM), CSV 가져오기(같은 내역은 중복으로 건너뜀)

## 구조

```
budget/index.html        화면
budget/css/style.css     스타일 (다크 모드 지원)
budget/js/ledger.js      금액 해석·합계·예산·고정 항목·CSV 등 순수 로직 (Node 테스트 대상)
budget/js/app.js         화면·저장(localStorage)
tests/budget.test.js     로직 테스트
```

## 참고한 기준

- CSV 내보내기 시 `=`, `+`, `-`, `@`로 시작하는 글자는 엑셀에서 수식으로 실행될 수 있어 앞에 `'`를 붙입니다. 출처: [OWASP – CSV Injection](https://owasp.org/www-community/attacks/CSV_Injection)
- CSV 형식(쉼표·따옴표·줄바꿈 처리)은 [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180)을 따릅니다.
- localStorage는 사이트(출처)별로 브라우저에 저장되며, 용량은 브라우저마다 다르지만 보통 수 MB 수준입니다. 출처: [MDN – Window.localStorage](https://developer.mozilla.org/ko/docs/Web/API/Window/localStorage), [MDN – Storage quotas](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)
- 작성 환경의 네트워크 제한으로 위 링크를 이 시점에 다시 열어 대조하지는 못했습니다.

## 알려진 제한

- 원화(정수) 전용이며, 여러 통화·계좌 잔고 관리는 지원하지 않습니다.
- 파일로 연 경우(`file://`) 일부 브라우저는 폴더마다 저장소를 따로 둘 수 있습니다. 같은 경로로 열어야 기록이 보입니다.
